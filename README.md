# MLB Dashboard

## Summary

This interactive dashboard visualizes historical Major League Baseball player statistics scraped from Baseball Almanac. Users can explore stats by year, team, and player, view top performers, and analyze player trends over time through dynamic charts.

## Features

- Select statistic, year, and team filters
- View top player for a selected statistic and year
- Click on a player to see their stats trend over all years
- Interactive and responsive visualizations using Plotly and Streamlit
